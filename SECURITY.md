# Security policy

## Supported versions

Until the first stable release, security fixes are applied to the latest published prerelease and the `main` branch.

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private security-advisory workflow for this repository. Do not open a public issue with exploit details, credentials, private data, or a proof of concept that could put users at risk.

Include the affected package and version, reproduction steps, expected impact, and any known mitigations. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.
