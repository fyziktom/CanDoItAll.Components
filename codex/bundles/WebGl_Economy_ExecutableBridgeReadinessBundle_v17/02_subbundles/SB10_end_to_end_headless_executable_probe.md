# SB10 — End-to-end headless executable probe

## Goal

Before UI demo, prove the whole chain as data + runtime commands.

## Required proof

For both generic probes:

1. load strict input pack;
2. validate hashes;
3. select backend;
4. materialize frames/deltas;
5. build visual frames/actions;
6. project WebGL run document;
7. validate bridge output;
8. execute or simulate application of stages through generic WebGlRun runtime/controller;
9. create snapshot at selected step;
10. analyze snapshot.

## Probes

- shared resource community;
- finite resource / constrained expansion.

Do not use final Blazor UI demo in this subbundle.
