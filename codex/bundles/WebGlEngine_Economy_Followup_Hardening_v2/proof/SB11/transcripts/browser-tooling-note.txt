SB11 browser tooling note

The Browser plugin skill was used as the preferred local browser capability for SB11. The in-app Browser connection exposed tab/page asset inspection but did not expose viewport-controlled navigation/actions needed for the required large+narrow proof matrix. Direct Playwright through the bundled Node runtime was used as the fallback for route navigation, viewport control, UI actions, screenshots, diagnostics JSON extraction, and console review.
