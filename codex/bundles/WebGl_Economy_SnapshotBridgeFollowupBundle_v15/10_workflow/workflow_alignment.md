# CanDoItAll workflow alignment

This bundle follows the CanDoItAll bundle workflow discipline:

- preserve raw findings
- map requirements to subbundles
- define dependency order
- require proof manifests
- require semantic invariants
- require changed-file hashes
- require source assertions
- close with solved / partial / not solved status

Codex must not treat prose as proof. Critical subbundles need artifact-backed proof.
