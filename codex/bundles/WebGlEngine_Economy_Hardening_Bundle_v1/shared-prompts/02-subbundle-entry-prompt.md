# Subbundle Entry Prompt

Use this prompt when starting a subbundle.

1. Identify the subbundle ID and title.
2. Read its prerequisites and confirm all required prior proof exists.
3. Read all exact source references.
4. List the requirements owned by the subbundle.
5. State the shallow-pass trap.
6. State the first negative proof to run or create.
7. Implement only the current subbundle scope.
8. Run the required tests/proof.
9. Complete the mandatory refactor gate.
10. Update proof, execution report, traceability and subbundle status.

Do not start downstream work in the same pass unless the subbundle explicitly allows it.
