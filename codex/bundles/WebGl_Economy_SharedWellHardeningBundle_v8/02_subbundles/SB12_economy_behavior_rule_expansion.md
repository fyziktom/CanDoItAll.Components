# SB12 — Economy: behavior/rule expansion

## Goal
Move closer to a real shared-well scenario without hardcoding all frames.

## Required work
Add a generic event expansion layer:
- actor daily resource need;
- actor travel to resource;
- actor collect/use resource;
- actor build inventory;
- actor sell resource;
- actor admin/paperwork;
- actor tax/fee payment;
- rule check;
- rule violation;
- rule enforcement;
- relationship/trust/conflict change.

## Keep generic
Names may be water/well in seed data, but the engine must operate on resources, stores, actors, rules, and events.
