# SB18 — Shared-well readiness proof

## Required proof
Add an explicit readiness document and tests showing what is supported and what is not.

Proof checklist:
- locations exist;
- actors have homes;
- shared resource location exists;
- daily use events exist;
- travel/use/return events exist;
- admin/rule events exist;
- visual actions can express move/use/return/admin symbol;
- distance-based trade is either implemented or explicitly listed as remaining work;
- no WebGL dependency in Economy.

## Acceptance
The proof must show the architecture remains generic. The word "well" may appear only in sample data, tests, and docs, not in generic engine code.
