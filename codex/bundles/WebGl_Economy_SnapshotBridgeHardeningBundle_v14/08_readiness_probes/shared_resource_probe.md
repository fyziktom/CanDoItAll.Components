# Shared-resource readiness probe

This is not a demo task. It is a generic readiness probe.

It should prove:
- actors have explicit input positions from placement JSON,
- actors need a resource,
- the source location is explicit,
- actors can collect/use/build inventory,
- distance/cost affects incentives,
- trade/resale can be represented without resource-specific fields,
- fee/tax/admin rules can emit events,
- visual mapping can show move -> perform -> admin -> return,
- snapshot at any step can explain current stores, issues, metrics, visual state.

Forbidden:
- generic code named after water/well/village.
