# Finite-resource ownership probe

This is not a demo task. It is a generic readiness probe.

It should prove:
- finite resources can be represented as stores/objects,
- ownership transfer can be represented as events,
- concentration can be measured,
- rule caps can be evaluated as invariants,
- visual mapping can show ownership, transfer, rule pressure,
- snapshot can show concentration state at any step.

- generic code named after farmer/land/oligarchy.
