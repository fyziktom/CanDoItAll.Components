# Workflow alignment

This bundle follows CanDoItAll workflow-bundle discipline:

- preserve branch, do not create a new one,
- keep source references,
- produce proof manifests,
- keep transcripts non-empty,
- add semantic invariants,
- add closure report,
- record changed file hashes,
- keep implementation matrix updated.

The final answer from Codex must include:
- what changed,
- what was intentionally not changed,
- commands run,
- test counts,
- warning count summary,
- remaining blockers for browser smoke.
