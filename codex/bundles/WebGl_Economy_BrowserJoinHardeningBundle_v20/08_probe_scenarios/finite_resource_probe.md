# Finite-resource probe

Use this as a second generic probe to prevent overfitting.

Required capabilities:
- finite resource stores,
- ownership transfer,
- concentration metric,
- anti-concentration rule,
- relationship/link visualization,
- snapshot analysis explaining concentration pressure.

Strict no-fallback target:
- actor/farm/institution/resource categories as generic visual categories,
- ownership transfer action,
- rule/warning symbol.
