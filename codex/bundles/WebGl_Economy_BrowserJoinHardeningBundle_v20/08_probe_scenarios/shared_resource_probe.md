# Shared-resource probe

Use this as a generic probe, not as a hard-coded well demo.

Required capabilities:
- actor movement to resource location,
- resource store usage/collection,
- distance-aware behavior,
- inventory capacity,
- resale/trade,
- fee/tax/admin visual action,
- rule issue visual action,
- snapshot analysis: admin burden, issue pressure, concentration, relationship stress.

Strict no-fallback target:
- actor asset mapping,
- resource asset mapping,
- institution asset mapping,
- admin pose,
- transfer action,
- warning/rule/tax symbols.
