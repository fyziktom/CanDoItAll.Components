# First browser smoke scope

This is not the final demo.

Build a minimal desktop-only Economy sandbox page that can:

1. Load a checked-in fixture input pack.
2. Project a session.
3. Display the initial WebGL scene.
4. Step to the next frame.
5. Apply that frame's command batch/stages to the WebGL runtime.
6. Pause.
7. Seek to a chosen step.
8. Create or select a snapshot.
9. Show snapshot analysis text/metrics.
10. Show bridge/runtime warnings.

Out of scope:
- mobile/small/medium screen work,
- final styling,
- full scenario editor,
- live multi-user session persistence,
- ledger backend UI.
