# Main weaknesses and remediation strategy

| Weakness | Noise risk | Remediation |
| --- | --- | --- |
| Partial domain leakage scan | Generic layer may become secretly Economy-shaped | Add configurable multi-scope scanner for src/tests/docs/artifacts; require driver-owned allowlists. |
| Domain driver not first-class enough | New domains may copy Economy assumptions | Define `IWebGlRunDomainMappingDriver`/driver manifest/driver validation contract and require non-economy canary. |
| Multi-goods semantic aliases | Investment/claim/elite effects may be simulated as plain transfer | Add exchange/investment semantic driver with explicit provenance and oracle tests. |
| Browser proof can be expected-vs-expected | UI can claim success while live runtime diverges | Export live document/scene snapshot and compare hashes/positions/stages/idle diagnostics. |
| Readiness booleans | Caller can accidentally overclaim research readiness | Evidence resolver must derive flags from artifacts and validators. |
| Large mutation hub | Refactoring risk and hidden coupling | Split store resolution, transfer/rejection, effects, relationships, and diagnostics. |
| Canary scenario incomplete | Genericity remains untested | Make multi-goods-elite a strict, oracle-covered, design-matrix-covered canary. |
