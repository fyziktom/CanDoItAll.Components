# Review limitations and assumptions

The Components repository was reviewed on the `webgl-engine` branch.

The Economy repository was reviewed on the default branch visible through GitHub. Branch searches for obvious WebGL/simulation/event branch names did not reveal a separate pushed branch through the available connector. Therefore this bundle assumes the visible default branch contains the latest Economy implementation.

If Codex has local commits or a different unpublished Economy branch, run SB01 first and update the inventory before executing later subbundles.
