# SB19 Governance Template

Authoritative governance doc:

- `docs/webgl/post-freeze-change-governance.md`

Required post-freeze packet:

- completed API change request when a frozen surface changes;
- focused failing-first proof when feasible;
- updated approval snapshots with rationale;
- domain-boundary hard-gate transcript;
- package-mode proof transcript;
- browser observer proof for runtime-visible behavior.

Disallowed:

- one-domain API widening;
- broad non-expiring allowlists;
- approval updates without migration rationale.
