- **COMP-SLN** (repo): Components solution includes WebGlLib, WebGlRunLib, sandbox and samples — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/CanDoItAll.Components.slnx — WebGlLib, WebGlRunLib, WebGlSandbox, WebGlLibOnlyViewer and WebGlRunLibGenericSample are in the solution.
- **COMP-PACKABLE** (repo): Default IsPackable=false, WebGL packages opt-in — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/Directory.Build.props — Directory.Build.props sets IsPackable=false; WebGlLib/WebGlRunLib set IsPackable=true.
- **WEBGLLIB-CSPROJ** (repo): WebGlLib package project — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlLib/CanDoItAll.Components.WebGlLib.csproj — WebGlLib is packable and references OverlayLib only.
- **WEBGLRUN-CSPROJ** (repo): WebGlRunLib package project — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlRunLib/CanDoItAll.Components.WebGlRunLib.csproj — WebGlRunLib is packable and references WebGlLib.
- **SCENEVIEW** (repo): WebGlSceneView remains public boundary and still broad — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlLib/Components/Scene/WebGlSceneView.razor — WebGlSceneView owns lifecycle, callbacks, import/export, patches, command batch and idle/stop APIs.
- **JSSURFACE** (repo): window.CanDoItAll.webglScene API surface — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlLib/wwwroot/js/runtime/scene/01-webgl-scene.js — JS API exposes create/update/import/export/proof/patch/command/motion/idle/stop methods.
- **CMDWAIT** (repo): Command batch and idle hard-fail mode — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlLib/wwwroot/js/runtime/scene/26-webgl-scene-command-batch.js — applyCommandBatchAndWait supports requireRuntimeIdle/hardFailOnIdleTimeout.

- **RUN-ACTIONS** (repo): Generic action kind vocabulary — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlRunLib/Actions/WebGlRunActionKinds.cs — Generic action kinds include DirectedFlowVisual and All approval set.
- **DOMAIN-DRIVER** (repo): Domain mapping driver contract — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlRunLib/DomainDrivers/WebGlRunDomainMappingDriver.cs — IWebGlRunDomainMappingDriver owns driver id/version, boundary options, mapping, scrubber, manifest and hash.
- **BOUNDARY-CI** (repo): Domain leakage CI workflow — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/.github/workflows/domain-leakage.yml — CI runs generic-source, public API, package content and docs/bundle audit profiles.
- **BOUNDARY-CONFIG** (repo): Domain boundary audit config — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/tools/webgllib/domain-boundary-audit.config.json — Config defines hard gates, soft docs audits and allowlist reasons.
- **WEBGLLIB-README** (repo): WebGlLib README and runtime hardening notes — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlLib/README.md — Documents asset cache ownership, compact lifecycle keys, revisions and patch classifications.
- **WEBGLRUN-README** (repo): WebGlRunLib README and observer proof notes — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/src/CanDoItAll.Components.WebGlRunLib/README.md — Documents run contracts, playback, observer proof and domain driver versioning.
- **WEBGLRUN-SAMPLE** (repo): Generic WebGlRunLib sample — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/samples/CanDoItAll.Components.WebGlRunLibGenericSample/Program.cs — Minimal generic run sample creates a route-like scene and motion without economy packages.
- **FREEZE-WEBGLLIB** (repo): WebGlLib freeze approval tests — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/tests/CanDoItAll.Components.WebGlLib.Tests/WebGlLibFreezeApprovalTests.cs — Approves public API, JS surface, JS API manifest and package content.
- **FREEZE-WEBGLRUN** (repo): WebGlRunLib freeze approval tests — https://github.com/fyziktom/CanDoItAll.Components/blob/webgl-engine/tests/CanDoItAll.Components.WebGlRunLib.Tests/WebGlRunFreezeApprovalTests.cs — Approves public API, action kinds, domain driver manifest and package content.
- **THREE** (external): Three.js docs — https://threejs.org/docs/ — Large API surface includes Object3D, InstancedMesh, LOD, loaders, materials, WebGL/WebGPU renderers and controls.
- **PLAYCANVAS-ENGINE** (external): PlayCanvas Engine docs — https://developer.playcanvas.com/user-manual/engine/ — Open source MIT JavaScript runtime engine with standalone engine, editor option, TypeScript declarations and examples.
- **PLAYCANVAS-ECS** (external): PlayCanvas ECS docs — https://developer.playcanvas.com/user-manual/ecs/ — ECS separates entities, components and systems; stresses flexibility, modularity and batched processing.
- **PLAYCANVAS-ASSETS** (external): PlayCanvas asset lifecycle docs — https://developer.playcanvas.com/user-manual/assets/ — Assets distinguish registry metadata from loaded runtime resources and define load/unload lifecycle.
- **PLAYCANVAS-OPT** (external): PlayCanvas optimization docs — https://developer.playcanvas.com/user-manual/optimization/ — Optimization goals include load time, frame rate, CPU/GPU load and memory usage.
- **REGL** (external): regl README — https://github.com/regl-project/regl — regl models WebGL as resources and complete draw commands; values simplicity, correctness, performance, minimalism and stability.
- **BABYLON** (external): Babylon.js homepage — https://www.babylonjs.com/ — Babylon highlights frame graph, editor, inspector, viewer, large world rendering and 3D Tiles support.
