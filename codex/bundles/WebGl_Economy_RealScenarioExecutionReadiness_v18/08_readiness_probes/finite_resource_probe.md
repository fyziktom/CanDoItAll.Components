# Finite Resource Probe

Use the farmer-land fixture only as a finite-resource concentration probe.

Generic expected behavior:

1. Resource units are owned by actors or institutions.
2. Transfers change stores.
3. Rule/invariant checks measure concentration or fairness.
4. Visualization maps ownership and pressure without special casing farms/land.
5. WebGL bridge produces stages and traceable commands.
6. Snapshot analysis exposes concentration metrics and rule pressure.

The same pipeline used for the shared-resource probe must work here.
