# Target Solution

- `bundle://01_architecture/01_target_architecture.md`
- `bundle://01_architecture/02_dependency_rules.md`

The durable target is two prepared but uncoupled repos:

- Components owns generic WebGL rendering, model diagnostics, generic run/playback contracts, and browser proof.
- Economy owns backend-neutral simulation contracts, simple-account scenarios, ledger adapter prep, economy visual-frame contracts, and boundary enforcement.
