# CanDoItAll workflow alignment

Use the same discipline as the main CanDoItAll Bundle Workflow skill:

- preserve raw findings;
- map findings to requirements and subbundles;
- execute one subbundle at a time;
- require entry and closure gates;
- record proof manifests and semantic invariants;
- keep changed-file hashes and command transcripts;
- perform raw-note closure audit;
- repair the bundle instead of drifting when implementation reality changes.

This bundle intentionally includes many small subbundles because the work crosses two repositories and touches deterministic experiment design, simulation semantics, WebGL runtime ordering, and future bridge design.
