# Shared-resource readiness probe

This is not a demo. It is a generic capability probe.

The probe passes when the system can express and validate:

- actors at different distances from a finite shared resource,
- resource need and acquisition,
- inventory build-up,
- resale/trade based on distance advantage,
- fees/taxes/admin burden based on rules,
- relationship or issue changes caused by rule enforcement,
- visual actions: move, perform, pose, symbol, return,
- snapshot analysis explaining why a paused visual state looks bad.

No generic production code may mention the concrete example ids.
