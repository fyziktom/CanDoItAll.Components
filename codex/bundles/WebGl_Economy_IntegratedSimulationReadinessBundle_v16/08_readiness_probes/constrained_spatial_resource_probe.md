# Constrained-spatial-resource readiness probe

This is not a demo. It is a generic capability probe.

The probe passes when the system can express and validate:

- finite resource units mapped to spatial objects,
- actors seeking expansion under external demand,
- ownership transfer or acquisition pressure,
- concentration metrics,
- anti-concentration rules and enforcement,
- visual actions: ownership transfer, admin/rule symbol, relationship pulse,
- snapshot analysis explaining concentration and rule pressure.

No generic production code may mention the concrete example ids.
