# SB12 - Generic readiness probes

## Goal
Use examples only to validate generic capabilities.

## Probe A: Shared finite resource

Validate the kernel supports:

- actor locations,
- shared source,
- distance cost,
- inventory building,
- resale/trade,
- admin burden,
- fee/tax/rule enforcement,
- issue and relationship changes,
- visual actions and stage sequences,
- snapshot analysis.

## Probe B: Constrained spatial resource

Validate the kernel supports:

- finite spatial resource,
- ownership stores,
- external demand,
- concentration metric,
- anti-concentration invariant,
- rule enforcement and cost,
- visual actions and snapshot analysis.

## Acceptance criteria

- No new production code has to reference example-specific ids.
- New probe scenarios can be expressed by JSON input packs and mapping files.
