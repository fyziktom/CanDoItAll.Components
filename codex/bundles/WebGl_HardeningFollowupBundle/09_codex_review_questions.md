# 09 - Codex review questions

Codex must answer these in the final implementation report:

1. Which files exceeded the maintainability size threshold before refactor?
2. Which files remain above threshold and why?
3. Which GLB/GLTF assets were discovered?
4. Which downloaded models were added as variants?
5. Which asset profile is default and why?
6. Which features are still only primitives/fallbacks?
7. How is drag implemented and how is camera-orbit conflict prevented?
8. How does `applyPatch` avoid full rebuild for transform-only changes?
9. How does motion interpolation stop exactly at target?
10. When does the render loop run continuously and when does it settle?
11. How are create/update/load failures surfaced?
12. Which tests/proofs verify old `WebGlWorkbench` compatibility?
13. What belongs to future `WebGlRunLib` and what remains in `WebGlLib`?
