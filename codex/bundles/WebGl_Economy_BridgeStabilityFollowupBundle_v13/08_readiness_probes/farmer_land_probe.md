# Farmer-land readiness probe

This probe prevents overfitting to shared-well.

A generic pipeline must support:

- finite spatial resource
- actor expansion pressure
- external buyer / market demand
- ownership transfer
- concentration metrics
- anti-concentration rules
- invariant failure if top share exceeds cap
- visual sequence:
  - trade/transfer
  - rule check
  - admin/tax/fee
  - warning/symbol/relationship pulse

Pass criteria:
- no special farmer or land logic in generic bridge.
- resource ids and rule definitions drive the behavior.
