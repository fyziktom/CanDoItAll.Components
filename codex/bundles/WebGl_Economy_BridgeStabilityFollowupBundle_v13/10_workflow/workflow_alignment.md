# Workflow alignment

This bundle follows the CanDoItAll bundle workflow principles:

- raw observations are mapped to subbundles;
- critical foundations have gates;
- proof must be artifact-backed;
- closure must cite commands, changed-file hashes, and semantic invariants;
- unresolved gaps become follow-up subbundles, not prose-only residual risk;
- current repository observations override memory from previous conversations.

Do not execute all subbundles as one unreviewed patch. Execute in dependency order.
