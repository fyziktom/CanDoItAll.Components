# Codex subbundle execution rule

For every subbundle:

1. Print current branch for both repositories if both are touched.
2. Do not create or switch to a new branch.
3. Implement only the current subbundle.
4. Run the subbundle validation.
5. If a file crosses threshold, stop and refactor before continuing.
6. Write evidence under `artifacts/webgl-economy-followup-v5/...`.
7. Update the closure checklist.
8. Only then proceed to the next subbundle.

All source code comments must be in English.
