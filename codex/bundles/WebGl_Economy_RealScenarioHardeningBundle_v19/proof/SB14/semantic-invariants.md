## Contract

SB14 is valid only if the proof artifacts are generated by production probes and runtime scripts, not by hand-authored placeholder JSON.

## Required Economy Invariants

- Headless scenario normalization reports exactly 100 actors, 500 resources, 500 stores, and 1000 events.
- Headless materialization emits at least the 1000 scheduled event frames plus the initial frame.
- Visual action normalization reports exactly 500 input and normalized actions with zero warnings.
- Deterministic final-frame hash generation reports a 64-character hash and completes under the 10000 ms threshold.
- Snapshot export/import still performs 100 production serializer round trips.

## Required WebGL Invariants

- WebGL scale proof reports exactly 500 scene objects, 1000 links, 1000 symbols, and 500 staged commands.
- Stage runner applies all 500 stages and drains the queued stage count to 0.
- Command stage journal count is bounded to 200 entries while retaining counters for all 500 started, applied, and completed stages.
- Journal overflow is observable through a positive dropped-entry count, proving old entries are trimmed instead of retained without bound.
- Runtime source assertions cite the production JavaScript journal bound and result-log cap.

## Anti-Fake Rules

- Passing tests alone are not enough; generated JSON must contain the required counts, thresholds, elapsed times, and bounded queue/journal facts.
- The proof must cite source hashes for both modified probes and generated performance artifacts.
- The anti-stub audit must find no TODO, NotImplemented, fake/stub markers, unconditional `return true`, or `Thread.Sleep` in the modified SB14 probe sources.
