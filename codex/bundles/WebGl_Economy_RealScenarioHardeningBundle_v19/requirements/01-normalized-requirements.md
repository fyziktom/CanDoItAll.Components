# Normalized Requirements

## R01 Branch And Boundary Guard

Record current branches and commits for Components and Economy, avoid branch creation, and prove dependency direction remains valid.

## R02 Components Runtime Hardening

Harden stage barriers, cancellation, missing-object motion waits, render-idle waits, event isolation, and bounded journal behavior.

## R03 Components Run Document Controller

Verify or implement a reusable Economy-free controller that can apply frame stages, navigate the document timeline, pause/resume, and export runtime snapshot data suitable for later Economy attachment.

## R04 Components Runtime Audit

Run and extend the JavaScript runtime audit for size thresholds, circular imports, duplicate helpers, unsafe `innerHTML`, and forbidden domain terms.

## R05 Economy Bridge Strictness

Harden strict WebGL bridge validation for missing commands, missing source ids and hashes, unresolved objects, disabled fallbacks, and structured diagnostics.

## R06 Economy Bridge Refactor

Keep projectors separated by responsibility, add a diagnostics aggregator, and test projectors in isolation.

## R07 Renderer-Neutral Mapping

Keep Economy abstractions and visualization renderer-neutral. Mark unavoidable bridge-bound WebGL fields with follow-up notes instead of leaking runtime semantics into generic models.

## R08 Headless Real Scenario Runner

Add a generic runner that exports validation, simulation, visualization, WebGL run document, snapshots, snapshot analysis, and readiness-report artifacts for required scenarios.

## R09 Snapshot Runtime Attachment

Attach WebGL runtime state to snapshots without mixing it into deterministic data state. Include separate hashes for data state and optional visual runtime state.

## R10 Snapshot Analysis Services

Move useful test-local snapshot analysis into reusable generic services with no water, well, farmer, land, or similar domain hard-coding.

## R11 Backend Selector And Ledger Readiness

Make backend selection deterministic, fail missing backends with structured diagnostics, add fake backend and ledger descriptor readiness tests, and prevent SimpleAccounts leakage into generic contracts.

## R12 Readiness Report

Produce a readiness report for shared-resource and finite-resource probes, and evaluate whether a small producer/community probe can be expressed without new core types.

## R13 Large-Screen Browser Smoke Plan

Prepare a large-screen-only smoke path for rendering one run document, playing one frame stage sequence, exporting diagnostics, and comparing completed stage ids. Do not build a final UI demo.

## R14 Performance Gates

Extend Economy and WebGL performance probes with the stated counts, thresholds, elapsed times, and bounded journal/queue checks.

## R15 Final Validation And Closure

Run required Components and Economy commands, capture non-empty transcripts, update proof manifests, close raw notes, run final validator, and record any follow-ups explicitly.
