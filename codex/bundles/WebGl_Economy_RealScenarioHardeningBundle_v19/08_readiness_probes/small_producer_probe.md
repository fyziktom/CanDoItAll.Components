# Small producer/community probe

This probe is optional in implementation but must be considered in the readiness report.

It should test whether existing generic model can express:

- actor production/work,
- input/output resource transformation,
- market demand or buyer actor,
- admin burden/tax/fee rule,
- trade/relationship changes,
- visual action sequence: work pose -> transfer flow -> symbol/update.

If new core types are needed, list them in the report but do not overfit them to one domain.
