# WebGL large-screen policy

WebGL surfaces in this repository are validated as desktop/large-screen experiences only.

Rules for this bundle wave:

- Use desktop proof viewports of `1440x900` or larger.
- Do not add small-screen or medium-screen optimization work for WebGL surfaces.
- Keep any below-minimum viewport handling limited to a clear unsupported-size warning.
- Do not add mobile, tablet, or phone screenshot gates for WebGL validation.
